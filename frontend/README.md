# YollIA Frontend

This folder contains the YollIA web application (to be added).

The web app will support two interfaces:
- **Agricultor**: simple Spanish-language experience with an embedded AI assistant.
- **Técnico**: detailed crop-planning and model information.

Both interfaces will use the same Python backend API in this repository. The planned WhatsApp integration will also use that backend.

> The frontend application code has not been added yet. This README initializes the directory without changing the existing scientific pipeline.
